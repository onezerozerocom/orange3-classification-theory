# 분류 모델 · 시뮬레이션 + 직접 풀기

교과서에 없는 **분류(KNN 알고리즘)** 를 시뮬레이션으로 살펴보고, 각 단계의 빈칸을 직접 채우는 웹앱입니다. 군집분석이론 앱과 같은 구조(lib.js · core.js · style.css · ws.css 공용)입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없습니다.

## 구성

| 단계 | 시뮬레이션 | 채우는 칸 |
| --- | --- | --- |
| 먼저 알아보기 | 기계 학습 = 지도 학습(분류·회귀) / 비지도 학습(군집·연관), [표1] 예제 과일 8개 | – |
| 1. 분류의 개념 | [그림1] 예제 과일과 ★ | 빈칸, 분류/회귀/군집 ○표, ★ 예상 |
| 2. 거리 재기 | (확인) ★을 끌면 각 과일까지 거리 | ★(5, 5)에서 A~H까지 거리 |
| 3. k-최근접 이웃 | (확인) 예제 k = 1~7 · 과일 41개에서 ★ 끌기, k 슬라이더 | 빈칸, 가까운 순위, k = 1·3·5 다수결, k = 2 문제 |
| 4. k 정하기 | 과일 41개 분류 경계 (k = 1~41), 끌 수 있는 ★ | k = 1·41 예측, 빈칸 (k 고르는 방법은 5단계) |
| 5. 모델 평가 | 새 과일 100개 학습 70 / 테스트 30, k별 학습·테스트 정확도 | 빈칸, 10개 O/X·정확도, 알맞은 k 고르기와 까닭 |
| 6. 종합 연습 | – | 객관식 5문항 + 저장 |

- 예제는 k = 1 → 레몬, k = 3 → 귤, k = 5 → 레몬으로 **k에 따라 결과가 바뀌도록** 만든 숫자입니다.
- 5단계 과일 100개는 시드 고정으로 만든 데이터입니다. k = 1이면 학습 100% / 테스트 83%(과적합), k = 5~8이면 테스트 97%, k ≥ 65이면 40%로 떨어집니다.
- 빈칸 근처에는 정답이 바로 보이는 내용을 두지 않았고, 확인용 시뮬레이션은 접힌 「확인」 안에 있습니다.

## 저장

오른쪽 위 **저장하기**(또는 Ctrl + S) → 이 브라우저(localStorage)에 저장. 서버로는 아무것도 보내지 않습니다.
